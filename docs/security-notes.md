# Security Notes

This repository contains example infrastructure configurations only.

## Important Security Practices

- Never commit real passwords, API keys, tokens, or private keys.
- Use `.env` files for secrets.
- Keep production IP addresses and domains private.
- Replace all sample passwords before deployment.
- Restrict admin panels using VPN or private access.
- Enable 2FA on GitHub and Cloudflare.
- Regularly update Docker images and host packages.
- Back up critical data before applying infrastructure changes.

## Disclaimer

The files in this repository are sanitized examples and should be reviewed before use in production.
